## Promotion criteria

A category can move toward autonomous publishing only if:
- identity drift is near zero;
- editorial correction rate is low;
- no governance violations;
- source use is reliable;
- timing/context is coherent;
- rollback works;
- audit trail is complete.

Autonomy can be revoked immediately.
