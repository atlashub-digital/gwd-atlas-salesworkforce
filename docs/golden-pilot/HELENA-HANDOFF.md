## 5. Event model

Critical rule:

```text
EVENT != POST
```

A simulated event can exist in the timeline without becoming public content.

Example:
- 12:20 — lunch;
- 15:40 — coffee;
- 19:00 — run;
- 22:10 — TV.

Only one of these may become a social draft.

This is required for realism and to avoid an always-posting synthetic feed.

## 6. Truth separation

### Real operational truth
Examples:

### Simulated persona truth

- going for a run;

- real customer relationships;
- physical presence;
